# 생기부 점검기

다른 선생님이 쓴 학교생활기록부 글을 2026학년도 기재요령(중학교판, 고등학교판) 기준으로 점검하고, 고칠 문구를 제안하는 도구입니다.

주소: https://176-oss.github.io/class/sgb-checker/

## 쓰는 순서

1. **시작**에서 학교급(중/고)과 학년을 고릅니다.
2. 점검할 항목을 고르고 엑셀을 올리거나 글을 붙여넣습니다.
3. **결과**에서 학생별 통과 / 확인 / 오류를 봅니다. 위쪽에 반 전체에서 많이 나온 지적 5개가 나옵니다.
4. [보기]를 누르면 원문에 밑줄(오류는 굵은 실선, 확인은 점선)이 생기고, 오른쪽에 지적이 나옵니다. 지적마다 이유와 기재요령 쪽수가 있습니다.
   - [적용]: 바꿀 문장으로 바꿉니다.
   - [예외 처리]: 사유(교육관련기관임, 고유명사임, 학교 기준상 허용, 직접 입력)를 고르면 지적이 회색으로 바뀌고 보고서에 사유가 남습니다.
   - [그대로 둠]: 지적을 접어 둡니다.
   - [정리]: 연속 공백, NEIS에서 깨지는 문자, 날짜 형식을 한 번에 고칩니다.
   - [되돌리기], [전후 비교]: 고치기 전과 후를 나란히 봅니다.
5. **보고서 내려받기**: 요약, 학생별, 수정본 세 시트로 된 엑셀을 작성한 선생님께 돌려드립니다.
6. [작성 도우미에서 고치기]: 고친 글 한 명을 작성 도우미로 보냅니다(새 탭).
7. [작성 도우미로 보내기]: 고친 글 전체를 보내면 작성 도우미가 최종본에 반영할지 물어봅니다. 반대로 작성 도우미의 [점검기로 보내기]로 반 전체를 받아 바로 점검할 수 있습니다 (위의 "작성 | 점검"으로 오갑니다).

결과 화면은 작성 도우미처럼 학생 표(글 전체 줄바꿈)와 오른쪽 상세 패널로 보이고, 엑셀 올리기 칸에는 파일을 끌어다 놓아도 됩니다.

## 엑셀 양식

[양식 내려받기]를 누르면 `학번 | 이름 | 과목 | 내용` 양식이 나옵니다. 과목은 세특에서만 씁니다.

- 한 파일에 여러 항목을 넣으려면 **시트 이름을 항목 이름**으로 하세요: `자율`, `동아리`, `진로`, `행특`, `세특_국어`, `개세특`, `일상생활`, `자유학기 진로탐색` 등.
- NEIS에서 내려받은 파일처럼 위에 제목 줄이 있어도 됩니다(첫 10행 안의 머리글을 찾습니다). 학번 대신 번호만 있어도 됩니다.
- 5MB, 시트 30개, 행 3,000개까지 엽니다. 셀 하나가 5,000자를 넘으면 앞부분만 읽고 '너무 김'으로 표시합니다.
- 빈 칸은 '미작성'으로 따로 셉니다.

## 항목별로 보는 것

공통: 바이트 한도(엔터 포함), 명사형 어미(~함, ~음, ~임), 관찰자 시점(나는, 그녀는, 학생 이름), 마침표, 두 칸 띄어쓰기, 번호·기호 문단 구분, NEIS 깨짐 문자, 기재 금지 내용, 과장 표현, 다른 학생과 90% 이상 비슷한 글, 3명 이상 같은 문장, 날짜 형식(`2026.03.04.`, `2026.03.04.-2026.07.08.`).

| 항목 | 더 보는 것 |
|---|---|
| 자율·자치 | 3학년인데 '자율·자치'라고 쓴 경우, (고) 학교명·축제명·별칭 |
| 동아리 | 본문의 동아리명 반복, 청소년단체(중: 단체명만, 고: 입력 불가), 자율동아리 소개 30자 |
| 진로 | 대학명, 기관명·상호명, 부모 직업 암시, 상업 검사 이름 |
| 세특 | 대회, MOOC, 방과후학교, 소논문(고등학교 탐구 과목 6개는 제목·주제·인원·시간만 금지), 강사명, (고) 공통과목 1·2 합산 500자 |
| 행특 | 300자, 방과후학교, 영재교육, 성장 관점 없이 부정적 표현만 있는 글 |

**우리 학교 행사 목록 (자율·진로)**: 설정에 행사명과 날짜를 붙여넣거나 엑셀·CSV(앞 칸 행사명, 뒤 칸 날짜)로 올려 두면, 자율·진로 글의 `행사명(날짜)`가 목록과 이름·날짜 모두 같은지 봅니다. 이름은 같은데 날짜가 다르면 목록 날짜로, 목록의 행사 이름 뒤에 날짜가 없으면 `행사명(날짜)`로 [적용]할 수 있습니다. 날짜는 목록에 있는데 이름이 다른 것과 목록에 없는 날짜는 '확인'으로 보입니다. 목록은 이 브라우저에만 저장됩니다.

'확인'은 꼭 틀린 것이 아니라 선생님이 한 번 보셔야 하는 것입니다. 교육청, 교육지원청과 직속기관은 쓸 수 있으니 [예외 처리]를 고르세요.

## AI 점검 (설정에서 켤 때만)

맞춤법·띄어쓰기, 다른 항목에 들어갈 내용, 나열식 문장, 수정 문구를 AI(Gemini)로 봅니다. 꺼져 있어도 규칙 점검은 모두 됩니다.

- **API 키는 작성 도우미와 함께 씁니다.** 작성 도우미 설정에 키를 넣었다면 점검기에서 다시 넣지 않아도 됩니다. 점검기에서 넣은 키도 작성 도우미가 씁니다(작성 도우미 후속 작업 뒤). 점검기에서 [이 브라우저에서 키 지우기]를 누르면 작성 도우미에서도 지워집니다.
- '이번에만 사용'은 이 탭에서만 쓰고 저장하지 않습니다.
- **결제가 연결되지 않은 무료 키**를 쓰세요. Google AI Studio에서 키 제한을 걸어 두세요: 웹사이트 `https://176-oss.github.io/*`, API는 Generative Language API만.
- AI가 만든 문구는 규칙 점검을 다시 통과해야 보입니다. 처음 적용할 때 '학생의 실제 활동과 맞는지 확인했습니다'에 표시해야 합니다(기재요령 19쪽: AI로 만든 글을 그대로 입력하지 않음).

## 개인정보

- 올린 엑셀과 글은 이 페이지 안에서만 다루고 **저장하지 않습니다.** 페이지를 닫으면 사라집니다. 설정(학교급, 한도, 학교 이름)과 API 키만 이 브라우저에 저장됩니다.
- AI로는 학번과 이름을 보내지 않고, 글 안의 명단 이름은 '학생'으로 가려서 보냅니다. AI를 켜기 전에 학교 개인정보 지침을 확인하세요.
- 보고서에는 학생 이름과 글이 들어 있습니다. **교내에서만 주고받으세요.**

## 개발

- 빌드 없음. 저장소 최상위에서 `python -m http.server`로 열고 `http://localhost:8000/sgb-checker/`.
- 테스트: `node --test sgb-checker/tests/` (패키지 설치 없음).
- 샘플 엑셀 다시 만들기: `node sgb-checker/tests/make-samples.mjs` (가상 학생 30명, `tests/samples/`).
- 구조와 형식: `docs/contract.md`. 검수: `docs/review.md`. 같은 주소 보안 점검: `docs/security-origin-audit.md`.
- 외부 코드는 불러오지 않습니다. SheetJS와 글꼴은 `lib/`에 있고 버전·해시는 `lib/README.md`에 있습니다.
