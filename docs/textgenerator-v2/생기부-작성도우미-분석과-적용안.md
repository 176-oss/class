# 생기부 작성도우미 v1.14 분석과 우리 도구 적용안

작성일: 2026-11-06 / 대상: 다른 교사가 만든 단일 HTML 도구(v1.14, 2026-08-12)와 사용 설명서 PDF
우리 도구: 구글 시트 + Apps Script + Gemini, 학번 5자리, 반 유형(담임반, 교과담임반, 동아리반). 기존 textgenerator는 그대로 두고 새로 만듦.

## 0. 저작권 (가장 중요)
- 원본 머리 주석: 무단 복제·배포·상업적 이용 금지, 2차적 저작물 작성·배포 금지, 교내 교사 비영리 사용만 허용.
- 따라서 코드, 프롬프트 원문, 내장 사전(금지어 433건 등)은 가져오지 않는다. 아이디어와 설계 방식만 참고하고, 구현·문구·금지어 목록은 교육부 기재요령 원문을 근거로 새로 만든다.

## 1. 원본 요약
- 브라우저 파일 하나(3MB, JS 약 13,000줄). 데이터는 PC 한 대의 IndexedDB·localStorage에 저장.
- 담임 모드(자율·자치, 진로, 행동특성 등) / 교과 모드(교과세특, 동아리).
- 기능: 명렬(양식, NEIS 출석부), 3단 편집기, 실시간 검증(바이트, 금지어, NEIS 비호환 문자), AI(내용 보강, 초안, 평가어, 검토, 자료 정리), 현황판, NEIS 한 명씩 붙여넣기, 세특 양식 채우기, 백업.
- 한도(고·중, 원본 기준): 교과세특·자율·자치·진로·동아리 1,500byte(500자), 행동특성 900byte(300자). 바이트는 한글 3, ASCII 1.

## 2. 장점 (참고할 아이디어)
- 영역 설정 표 하나로 한도·모드 관리
- NEIS 바이트 계산, 비호환 문자·연속 공백 검사
- 메모에 있는 사실만 쓰게 하는 초안 원칙, "내용 부족" 고정 응답
- 메모 분량에 따른 분량 지시, 한도/2.6으로 글자 수 환산
- 보내기 전 개인정보 가리기, 받은 뒤 호칭 삭제
- 모델 자동 전환과 쉬운 한국어 오류 안내
- 상태(미작성/작성중/초과/완료)와 완료 잠금
- NEIS 출석부를 명렬로 바로 사용, 한 명씩 붙여넣기 도우미
- 가져오기 전 미리보기 통계와 되돌리기 지점
- 학생 간 90% 이상 비슷한 글 감지

## 3. 단점과 위험
- API 키를 평문 저장하고 URL에 붙여 전송
- 비밀번호 잠금은 화면만 가림, 데이터 암호화 없음
- PDF 첨부는 가리지 않고 원본 그대로 AI로 전송
- 데이터가 PC 한 대에 묶이고 자동 백업도 같은 저장소 안에 있음
- 금지어가 세 군데 따로 있고 검사가 단순 부분 일치(오탐)
- AI 결과 검증 한도가 1,500으로 고정(행동특성 900에서 틀림)
- 버튼과 기능이 너무 많음, 초안을 한 명씩만 생성
- 기재요령·성취기준 1.7MB가 코드에 박혀 매년 재배포 필요

## 4. 우리 구글 시트 도구 적용안
꼭 가져올 것 (구현은 새로)
1. `설정` 시트의 영역 표(영역, 반 유형, 바이트 한도)
2. 바이트·한도·상태 열과 조건부 서식
3. 사실만 쓰는 초안 원칙, 내용 부족 고정 응답, 명사형 종결
4. 메모 분량별 분량 지시
5. 이름·학번은 AI에 보내지 않음 (행으로만 연결)
6. 생성 후 자동 검사 결과를 `검사` 열에
7. 완료 행은 일괄 작업에서 건너뜀
8. 모델 목록을 설정 시트에 두고 자동 전환

고쳐서 가져올 것
1. API 키는 사용자 속성(PropertiesService)에 저장, 서버에서 헤더로 호출
2. `금지어` 시트 하나(단어, 분류, 근거, 대체 표현, 적용 영역)를 검사와 프롬프트가 함께 읽음
3. NEIS 출석부 머리글 자동 탐색, 저장할 때 5자리 학번으로 합침
4. 동아리반도 학번으로 연결
5. AI 검토 결과는 메모 열에, 일괄 실행은 6분 제한에 맞춰 나눠 처리
6. 원본에 없는 일괄 초안 생성(선택 행, 간격, 중단, 이어하기)
7. 가져오기 전 미리보기 + `백업_날짜` 시트 자동 복사

가져오지 않을 것
- 원본 코드·프롬프트·사전 복사, 브라우저 저장소 구조, 화면 잠금 비밀번호, 내장 대용량 데이터, 외부 서버 버전 확인, 부가 버튼 다수

## 5. 디자인
- 원본: 잉크 그린 주색 + 베이지 바탕, 글꼴 3종(본문, 세리프, 고정폭), 영역별 색 9개.
- 우리: 꿀색 계열 3색(#6B4410, #C98A1B, #FBEFD5) + 경고 빨강(#B42318), IBM Plex Sans KR 한 가지(구글 시트 셀과 사이드바 공통), 이모지·기호 문자 없음, 영역 구분은 글자 라벨로.
- 미리보기 시안: 작성 탭+사이드바, 현황 탭, 명단 탭, 사이드바 단계(검사, NEIS 옮기기, 처음 설정).

## 6. 남은 확인
- 영역별 한도는 2026 기재요령 원문으로 다시 확인
- 학교 개인정보 지침상 Gemini 사용 가능 여부
- NEIS 자동 입력은 이번 범위에서 제외 (복사 도우미까지)
