📅 에듀타임 시간표 위젯 설치 가이드

우리 학교 시간표를 바탕화면에서 가장 빠르고 예쁘게 확인하세요.

💻 윈도우 (Windows) PC 위젯 설치 방법

  1. 아래의 다운로드 버튼을 눌러 깃허브에서 최신 버전 압축 파일(.zip)을 다운로드합니다.
  2. 원하는 곳(예: 바탕화면이나 문서 폴더)에 압축을 풉니다.
  3. 폴더 안에 있는 edutime.exe(버전이 적힌 파일)를 더블클릭하면 바탕화면에 위젯이 뜹니다!
  4. ※ 이후 새로운 업데이트가 나오면 위젯을 켤 때 자동으로 알려주며, 아주 쉽게 덮어쓰기 업데이트가 가능합니다.
윈도우 PC 위젯 다운로드

🍎 아이폰 (iOS) 설치 방법

  1. App Store에서 'Scriptable' 앱을 무료로 다운로드합니다.
  2. 앱을 열고 우측 상단의 [ + ] 버튼을 누릅니다.
  3. 아래의 [코드 복사하기] 버튼을 눌러 전체 코드를 복사한 뒤, 빈 화면에 붙여넣고 저장(Done)합니다.
  4. 바탕화면으로 나가서 꾹 누른 뒤, 좌측 상단 [ + ]를 눌러 Scriptable 위젯을 꺼냅니다.
  5. 위젯을 터치해 Script : Untitled Script / When Interacting : Run script / Parameter : '빈칸' 끝!
코드를 불러오는 중입니다... 잠시만 기다려주세요 ⏳

💡 초강력 꿀팁: '스마트 스택'으로 3주치 시간표 한눈에 보기

위젯 3개를 겹쳐서 [지난주 - 이번주 - 다음주] 시간표를 손가락 제스처로 넘겨볼 수 있는 무적의 스택을 만들어보세요!

  • 1단계 : 바탕화면 꾹 누른 뒤 '스마트 스택' 위젯을 꺼냅니다.
  • 2단계 : 스택 안에 있는 다른 위젯을 [-]를 눌러 다 지웁니다.
  • 3단계 : 왼쪽 위 [+]를 눌러 scriptable 위젯 3개를 꺼냅니다. 위젯을 터치해 [위젯 편집]으로 들어간 뒤, Parameter(매개변수) 칸에 다음과 같이 숫자를 입력합니다.
    • 지난주 위젯 Parameter ➔ -1 입력
    • 이번주 위젯 Parameter ➔ 0 입력 (또는 비워두기)
    • 다음주 위젯 Parameter ➔ 1 입력

🤖 안드로이드 (Android) 설치 방법(!!수정중!!)

  1. 아래의 다운로드 버튼을 눌러 APK 설치 파일을 다운로드합니다.
  2. 다운로드된 파일을 실행하고, '출처를 알 수 없는 앱 설치'를 허용해 줍니다.
  3. 바탕화면을 꾹 눌러 '위젯' 메뉴에서 에듀타임 시간표를 꺼내면 끝!
