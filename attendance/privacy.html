출결관리 도우미 개인정보처리방침

시행일: 2026년 10월 30일

출결관리 도우미(이하 "앱")는 담임교사가 출결 기록과 증빙서류를 관리하도록 돕는 웹 앱입니다. 앱은 개발자의 서버를 운영하지 않으며, 개발자는 사용자의 정보를 수집하거나 전송받지 않습니다.

1. 저장되는 정보

  • 사용자가 입력한 학생 명단, 출결 기록, 증빙서류 정보
  • 구글 연결 정보(접근 토큰, 마지막 연결 상태)

2. 저장 위치

  • 사용자 기기의 브라우저 저장소(localStorage, IndexedDB)
  • 사용자가 구글 계정을 연결한 경우, 사용자 본인의 구글 드라이브 앱 전용 폴더(appDataFolder). 이 폴더는 이 앱만 접근할 수 있고 드라이브의 다른 파일은 볼 수 없습니다.

3. 구글 사용자 데이터

앱은 구글 드라이브 범위 https://www.googleapis.com/auth/drive.appdata 하나만 요청합니다. 이 범위는 앱 전용 폴더의 읽기와 쓰기에만 쓰이며, 기록을 여러 기기에서 동기화하는 목적 외에는 사용하지 않습니다. 앱은 구글 사용자 데이터를 개발자나 제3자에게 전송, 판매, 공유하지 않으며 광고에도 사용하지 않습니다.

4. 보관과 삭제

  • 앱 설정에서 구글 연결을 해제하면 기기에 저장된 접근 토큰이 삭제되고 구글에 토큰 폐기가 요청됩니다.
  • 기기의 브라우저 데이터를 삭제하면 로컬 기록이 지워집니다.
  • 드라이브의 앱 데이터는 구글 계정 설정(보안 → 계정에 연결된 서드 파티 앱)에서 앱 연결을 해제하며 삭제할 수 있습니다.

5. 제3자 제공

개발자는 사용자의 정보를 제3자에게 제공하지 않습니다. 구글 로그인과 드라이브 저장은 구글의 서비스이며 구글 개인정보처리방침이 적용됩니다.
