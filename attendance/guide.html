사용 안내

휴대폰·태블릿·PC 어디서나 출결과 증빙서류를 기록하고, 학교 PC에서 나이스 일일출결관리(담임용)에 반자동으로 옮깁니다. 학부모확인서 월 2회, 생리통 월 1회 한도도 자동으로 확인합니다.

5분 요약: 학교 PC에 확장프로그램 연결

그림을 따라 8단계를 하면 됩니다. 단계를 누르면 해당 설명으로 이동합니다.

  1. 1설치 파일 받기앱 설정에서 [확장프로그램 내려받기]
  2. 2압축 풀기지우지 않을 폴더에 풀어 둡니다
  3. 3확장 프로그램 관리 화면 열기크롬 주소창에 chrome://extensions
  4. 4개발자 모드 켜고 폴더 불러오기[압축해제된 확장 프로그램을 로드합니다]
  5. 5설치 확인과 고정퍼즐 아이콘에서 핀 고정
  6. 6나이스에서 사이드 패널 열기일일출결관리(담임용) 화면에서 아이콘 클릭
  7. 7구글 연결앱과 같은 구글 계정으로 로그인
  8. 8명단 불러오기[나이스에서 명단 불러오기]

1. 앱 설치 (휴대폰·태블릿)

앱스토어 없이 홈 화면에 추가하면 일반 앱처럼 열립니다.

  1. 휴대폰에서 앱 주소를 엽니다.
  2. 아이폰: Safari 아래쪽 공유 버튼 → 홈 화면에 추가
  3. 안드로이드: 크롬 오른쪽 위 메뉴 → 앱 설치 (또는 홈 화면에 추가)
  4. 처음 열면 학년도, 학년, 반, 학생 수를 입력합니다.

기록하는 법

종류교시 입력예
결석없음하루 전체 없음
지각몇 교시까지 없었는지지각 3교시 = 조회~3교시 없음
조퇴몇 교시부터 없었는지조퇴 2교시 = 2교시~종례 없음
결과빠진 교시를 모두 선택4, 5교시만 없음

자주 쓰는 사유(복통, 감기, 몸살, 생리통, 교외체험학습)를 누르면 구분과 필요한 서류가 자동으로 선택됩니다. 구분·사유 버튼의 순서는 설정의 구분 순서 [바꾸기], 자주 쓰는 사유 [편집]에서 바꿀 수 있고 학교 PC 확장프로그램에도 같이 적용됩니다.

2. 확장프로그램 설치·연결 (학교 PC, 약 5분)

나이스 화면 옆에 사이드 패널로 열려, 기록을 나이스에 옮겨 줍니다. 아래 그림 순서대로 따라 하세요.

준비물: 학교 PC의 크롬, 앱에서 쓰는 구글 계정. 그림을 누르면 크게 볼 수 있습니다.

1

설치 파일 받기

학교 PC의 크롬에서 앱을 열고 설정의 '학교 PC 확장프로그램' 카드에서 [확장프로그램 내려받기]를 누릅니다. 아래 버튼으로 바로 받아도 됩니다. attendance-extension.zip 파일이 다운로드 폴더에 저장됩니다.

attendance-extension.zip 내려받기앱 열기

막히면

내려받기가 안 되거나 파일이 열리지 않아요
학교 보안 설정으로 압축 파일 내려받기가 막혀 있을 수 있습니다. 정보 담당 선생님께 문의해 주세요.
2

압축 풀기

받은 압축 파일에서 마우스 오른쪽 → 압축 풀기(또는 모두 압축 풀기)를 누릅니다.

문서 폴더처럼 지우지 않을 곳에 두세요. 폴더를 지우면 확장프로그램도 사라집니다.

막히면

폴더 안에 같은 이름의 폴더가 한 번 더 들어 있어요
압축을 푼 곳에 attendance-extension 폴더가 겹쳐서 보이면, manifest.json 파일이 바로 보이는 안쪽 폴더를 4단계에서 선택합니다.
압축 풀기 메뉴가 보이지 않아요
압축 파일을 두 번 눌러 연 뒤 [모두 압축 풀기]를 누르거나, 안에 있는 폴더를 문서 폴더로 끌어다 놓습니다.
3

확장 프로그램 관리 화면 열기

크롬 주소창에 아래 주소를 입력하고 Enter를 누르면 위와 같은 화면이 열립니다. 이 주소는 크롬이 보안상 웹페이지의 링크로는 열 수 없게 막아 두었으므로, [주소 복사]를 누른 뒤 크롬 주소창에 붙여넣기(Ctrl+V) 하고 Enter를 누르세요.

chrome://extensions

막히면

주소를 열 수 없어요
크롬 오른쪽 위 점 세 개 메뉴 → 확장 프로그램 → 확장 프로그램 관리로도 열 수 있습니다. 그래도 열리지 않으면 학교에서 막아 둔 것이므로 정보 담당 선생님께 문의해 주세요.
4

개발자 모드 켜고 폴더 불러오기

  1. 오른쪽 위 개발자 모드 스위치를 켭니다.
  2. 왼쪽 위에 나타난 [압축해제된 확장 프로그램을 로드합니다]를 누릅니다.
  3. 파일 선택 창에서 2단계에서 푼 attendance-extension 폴더(manifest.json이 바로 보이는 폴더)를 고르고 [폴더 선택]을 누릅니다.

'개발자 모드' 사용 경고 안내가 뜨면 닫으면 됩니다.

막히면

[로드] 버튼이 보이지 않아요
개발자 모드가 꺼져 있는 것입니다. 오른쪽 위 스위치를 켜 주세요. 켜도 버튼이 없거나 스위치를 누를 수 없으면 학교에서 막아 둔 것이므로 정보 담당 선생님께 문의해 주세요.
폴더를 골랐는데 오류가 나요
manifest.json이 바로 들어 있는 폴더를 골랐는지 확인합니다. 폴더 안에 같은 이름 폴더가 한 번 더 있으면 안쪽 폴더를 고르세요.
5

설치 확인과 고정

목록에 출결관리 도우미 - 나이스 연동이 보이고 오른쪽 스위치가 켜져(파랑) 있으면 설치된 것입니다.

크롬 오른쪽 위 퍼즐 모양 아이콘을 눌러 핀 모양으로 고정해 두면 주소창 옆에 아이콘이 항상 보입니다.

6

나이스에서 사이드 패널 열기

나이스에서 학급담임 → 출결관리 → 일일출결관리(담임용) 화면을 엽니다. 주소창 옆 출결관리 도우미 아이콘을 누르면 오른쪽에 사이드 패널이 열리고 '나이스 화면 감지됨'이 보입니다.

이미 열어 둔 나이스 화면이라면 먼저 새로고침(F5)한 뒤 아이콘을 누르세요.

막히면

패널이 안 열리거나 감지되지 않아요
나이스 화면에서 F5를 누른 뒤 다시 아이콘을 누릅니다. 그래도 안 되면 확장 프로그램 관리 화면(3단계)에서 출결관리 도우미의 새로고침(둥근 화살표) 버튼을 누르고, 나이스 화면에서 F5를 한 번 더 누릅니다.
7

구글 연결

사이드 패널 [설정] 탭에서 [구글 연결]을 누르고 앱과 같은 구글 계정으로 로그인합니다. 같은 계정이어야 휴대폰 기록이 학교 PC에 나타납니다.

'확인되지 않은 앱' 화면이 나오면 [고급] → [출결관리 도우미(으)로 이동]을 누릅니다. 개인정보 처리 내용은 개인정보처리방침에서 확인할 수 있습니다.

앱 열기개인정보처리방침

막히면

구글 연결에서 오류가 나요
화면에 나온 오류 문구를 그대로 적거나 캡처해서 알려 주세요. 로그인 창이 보이지 않으면 팝업 차단이 켜져 있는지 확인합니다. 구글 연결 없이 백업 파일로 옮겨 쓰는 방법은 아래 4번에 있습니다.
8

명단 불러오기

나이스 일일출결관리 화면을 연 상태에서 사이드 패널 [명단] 탭의 [나이스에서 명단 불러오기]를 누르고 번호와 이름을 확인합니다.

여기까지 끝났습니다이제 [나이스 입력] 탭에 앱에서 기록한 내용이 나타납니다. 처음에는 3번 '처음 시험하기'부터 해 보세요.
확장프로그램이 하는 일과 하지 않는 일 날짜 이동, 학생 찾기, 출결마감구분 팝업 채우기와 [적용], 교시 칸 표시까지 자동으로 합니다. 나이스 [저장]은 선생님이 사이드 패널에서 [확인 완료 · 저장] → [이대로 저장]을 누른 뒤에만 누릅니다. 출결마감, 마감취소, 장기결석, 출력 버튼과 [조회] 때 뜨는 확인창은 절대 누르지 않습니다.

3. 처음 시험하기

처음에는 아래 순서로 안전하게 시험해 보세요. 나이스에는 아무것도 저장되지 않습니다.

  1. 학생 1~2명만 있는 날짜 하나로 [나이스 입력 시작]을 누릅니다.
  2. 자동 입력이 끝나 확인 단계가 되면 저장하지 말고 [멈추기]를 누릅니다.
  3. 나이스 [조회]를 눌러 표를 원래대로 되돌립니다.
  4. 이상이 없으면 그다음에 학생 1명이 있는 날짜로 저장까지 시험합니다.

시험 중에는 휴대폰에서 기록을 고치지 말고, 출결마감은 누르지 마세요. 이상한 점이 있으면 사이드 패널 [작업 기록 보기]를 캡처해 두세요.

나이스 입력 순서 전체 보기

미입력 기록을 날짜 순서대로 자동 입력하고, 날짜마다 선생님이 확인한 뒤 저장합니다.

  1. 나이스 → 학급담임 → 출결관리 → 일일출결관리(담임용)을 엽니다. 사이드 패널에 '나이스 화면 감지됨'이 보이는지 확인합니다.
  2. 처음 한 번: 사이드 패널 [명단] → 나이스에서 명단 불러오기 → 번호와 이름을 확인합니다. 구글 드라이브에 연결되어 있으면 이 명단이 드라이브에도 올라가 휴대폰 앱에서 이름으로 검색할 수 있습니다. 앱에서 먼저 등록한 명단이 있으면 나이스에서 불러오기 전에도 이름이 표시됩니다.
  3. [나이스 입력] → 나이스 입력 시작. 미입력 기록이 있는 가장 이른 날짜로 이동합니다.
  4. 구분이 '미정'이거나 사유가 빈 '기타' 기록이 있으면 먼저 구분·사유를 정합니다. 정한 내용은 앱 기록에도 반영됩니다.
  5. 그 날짜 학생들을 멈춤 없이 자동으로 입력합니다 (팝업 채우기, [적용], 기준 교시 표시). 나이스에 이미 다른 값이 있는 학생, 같은 날 기록이 2건인 학생, 교시 마감된 칸, 이름이 다른 학생은 입력하지 않고 목록에 '제외'로 표시합니다.
  6. 확인: 나이스 표에서 입력한 행은 파란색, 확인이 필요한 행은 빨간색으로 표시됩니다. 사이드 패널 목록에서 학생마다 기록과 나이스 값을 함께 볼 수 있습니다.
  7. 고치기 (사이드 패널): 고칠 학생의 [수정]을 눌러 구분·종류·교시·사유를 바꾸거나 [삭제 (이날 출석으로)]를 누릅니다. 앱에 없는 학생은 [학생 추가]로 넣습니다. 여러 명을 고친 뒤 [수정 반영 후 다시 입력]을 한 번 누르면 앱 기록을 고치고, 나이스 [조회]로 그 날짜를 다시 불러와 처음부터 다시 입력한 뒤 확인 화면으로 돌아옵니다. 나이스 팝업에서 직접 고쳐도 되며, 그 뒤 [다시 읽기]를 누르세요. 직접 고친 값은 저장할 때 앱 기록에 반영됩니다. 단, 직접 고친 뒤 사이드 패널 수정을 반영하면 [조회] 때문에 직접 고친 값이 지워지므로 경고가 나옵니다.
  8. [확인 완료 · 저장]을 누르면 나이스 표의 최종값을 앱 기록과 비교해 바뀐 점을 보여 줍니다. 나이스에서 지운 학생은 '앱 기록 삭제 / 앱 기록 남기고 자동 입력에서 빼기', 앱에 없는 학생은 '앱에 추가 / 무시'를 고릅니다. 교시 표시가 기대와 다르면 나이스 표를 보고 [확인함]을 체크합니다.
  9. 확장프로그램이 입력하지 않은 칸이 바뀌어 있으면(예: 다른 학생 칸을 실수로 누름) 저장하지 않고 번호와 나이스 값을 보여 줍니다. 나이스에서 그 칸을 되돌리거나 [조회]로 처음부터 다시 하세요. [무시]를 고른 행도 나이스에서 되돌려야 저장할 수 있습니다.
  10. [이대로 저장]을 누르면 다른 기기에서 그 날짜 기록이 바뀌지 않았는지 한 번 더 확인한 뒤 앱 기록을 고치고, 나이스 [저장]과 "저장하시겠습니까?" 확인을 자동으로 누른 뒤 다음 날짜로 넘어갑니다. 나이스 [저장]을 누른 뒤에는 멈출 수 없으니 끝날 때까지 기다려 주세요.
  11. 같은 날 기록이 2건인 학생, 나이스에 학생 목록이 없는 날짜(휴일 등)는 자동으로 입력하지 않고 '직접 확인이 필요한 기록'에 남깁니다. 나이스에서 직접 입력한 뒤 기록마다 [입력 완료로 표시]를 누르세요.
언제든 [멈추기] 멈추면 그 날짜는 저장되지 않습니다. 나이스 [조회]를 누르면 표가 원래대로 돌아갑니다. 나이스 알림(예: '일자가 변경되었습니다')이나 [조회] 확인창이 뜨면 확장이 멈추고 그 문구를 그대로 보여 줍니다. 확인창은 선생님이 직접 고르세요.

4. 기기 사이 동기화 (구글 드라이브)

구글 연결 없이도 '이 기기에만 저장' 모드로 바로 쓸 수 있습니다. 휴대폰 기록을 학교 PC로 옮기려면 둘 중 하나를 씁니다.

방법하는 법
구글 드라이브 연결앱 [설정] → 구글 드라이브 연결, 확장 사이드 패널 [설정] → 구글 연결. 같은 구글 계정으로 로그인하면 자동으로 맞춰집니다. 앱을 켜 둔 동안 20초마다 바뀐 내용을 확인하므로, 학교 PC에서 고치거나 나이스에 입력한 기록이 앱을 다시 열지 않아도 반영됩니다.
백업 파일앱 [설정] → 백업 파일 내보내기 → 학교 PC 사이드 패널 [설정] → 백업 파일 가져오기

학생 이름으로 찾으려면 앱 [설정] → 학생 명단에서 번호와 이름을 붙여넣어 등록하세요 (한 줄에 한 명). 오늘 탭의 '번호 또는 이름' 칸, 기록·서류·학생 탭에서 번호나 이름, 초성(예: ㄱㅅㅇ)으로 찾을 수 있습니다.

개인정보 학생 이름은 명단을 등록한 경우에만 구글 드라이브 앱 전용 폴더에 저장됩니다. 출결 기록에는 번호만 저장됩니다. 이름과 사유가 같은 파일에 저장되므로 학교 개인정보 지침을 확인해 주세요. 파일은 각 선생님 본인 구글 드라이브의 숨은 앱 전용 공간에 있으며, 제작자에게 전달되지 않습니다. 명단은 앱 [설정] → 학생 명단에서 언제든 지울 수 있습니다. 자세한 내용은 개인정보처리방침을 확인해 주세요.
