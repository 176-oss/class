Gemini API 키 발급 방법

1. Google AI Studio 접속:
https://aistudio.google.com/에 접속하여 구글 개인계정으로 로그인합니다.(학교 계정은 안됩니다!!)

2. API Key 생성:
왼쪽 하단의 'Get API key' 메뉴를 클릭한 후, 오른쪽 상단'API 키 만들기'-'키만들기' 버튼을 누릅니다.(무료 등급이어도 상관없어요!)

3. 키 복사 및 입력:
생성된 문자열을 복사하여 본 서비스의 API Key 입력란에 붙여넣으세요.

주의: API 키는 개인 자산입니다. 타인에게 공유되지 않도록 주의하세요. 무료 플랜은 분당 요청 횟수 제한이 있을 수 있습니다.
