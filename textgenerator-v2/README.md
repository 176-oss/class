# 생기부 작성 도우미 v2 사용 안내

학생 명단을 등록하고, 메모를 바탕으로 AI 초안을 받아 최종본을 다듬은 뒤, 나이스에 옮기는 일을 돕는 웹페이지입니다. 설치할 필요 없이 크롬에서 주소만 열면 됩니다.

주소: https://176-oss.github.io/class/textgenerator-v2/

## 1. 처음 설정
1. **설정** 화면에서 학교급(고등학교/중학교), 학년도, 학기를 고릅니다.
2. **영역별 바이트 한도**를 확인합니다. 기본값은 교과세특·자율·자치·진로·동아리 1,500바이트, 행동특성 900바이트입니다. 학교 기준이 다르면 고쳐 주세요. 한글은 한 글자에 3바이트, 영문·숫자·띄어쓰기는 1바이트로 셉니다.
3. **API 키**를 넣습니다 (아래 2절).
4. **명단** 화면에서 반을 만들고 학생을 등록합니다.
   - 반 종류: 담임반(자율·자치, 진로, 행동특성, 동아리), 교과반(교과세특, 과목명 입력. '같은 과목 반 여러 개 만들기'를 켜고 학년과 반 번호(예: 1-5, 7)를 적으면 '통합과학 1-1'처럼 한 번에 만듦. 이렇게 만든 반에서는 명단 등록 때 '학번의 반 번호대로 나눠 넣기'를 켜면 한 학년 명단을 한 번에 올려 반마다 나눠 넣을 수 있음), 동아리반(동아리).
   - 등록 방법: 엑셀 양식을 내려받아 채워 올리기, 나이스 출석부 엑셀을 그대로 올리기, 표에서 복사해 붙여넣기.
   - 학번은 5자리입니다 (학년 1자리 + 반 2자리 + 번호 2자리, 예: 3학년 5반 3번은 30503). 틀린 행은 행 번호와 고치는 방법을 알려 줍니다.
   - 한 학생이 담임반과 동아리반처럼 여러 반에 있어도 됩니다.

## 2. Gemini API 키 발급
1. https://aistudio.google.com 에 들어갑니다. 학교 계정이 아니라 **개인 구글 계정**으로 로그인하세요.
2. 'Get API key'(API 키 만들기)를 눌러 키를 만들고 복사합니다.
3. 이 페이지 **설정 > API 키**에 붙여 넣고 보관 방식을 고릅니다.
   - **이 브라우저에 저장**: 다음에 열어도 키가 남아 있습니다. 혼자 쓰는 PC에서만 고르세요.
   - **이번에만 사용**: 창을 닫으면 키가 지워집니다. 여럿이 쓰는 PC에서는 이것을 고르세요.
- 키는 Google 서버로만 보내며, 백업 파일·엑셀·드라이브 자동 백업에는 들어가지 않습니다.
- **구글 드라이브에도 저장** (선택, 기본은 꺼짐): 설정의 API 키 칸 아래 체크를 켜면 키가 구글 드라이브 앱 폴더의 데이터 파일에 함께 저장되어, 다른 PC에서 연결할 때 '드라이브에 저장된 API 키를 쓸까요?'라고 묻습니다. 결제를 연결하지 않은 **무료 키**를 쓰고, 아래 키 제한을 꼭 걸어 두세요. 공용 PC 설정을 켜면 이 기능은 쓸 수 없습니다. 체크를 끄거나 [키 지우기]를 누르면 드라이브의 키도 지웁니다.

### API 키 제한하기 (권장)
키가 새더라도 다른 곳에서 쓰지 못하게 막는 방법입니다.
1. https://console.cloud.google.com/apis/credentials 에 키를 만든 구글 계정으로 들어갑니다 (AI Studio의 키 목록에서 키 이름을 누르면 같은 곳으로 갑니다).
2. 목록에서 이 앱에 쓰는 API 키 이름을 누릅니다.
3. **애플리케이션 제한사항**에서 **웹사이트**를 고르고, 웹사이트 제한사항에 `https://176-oss.github.io/*` 를 추가합니다.
4. **API 제한사항**에서 **키 제한**을 고르고, 목록에서 **Generative Language API** 하나만 체크합니다.
5. **저장**을 누릅니다. 적용까지 몇 분 걸릴 수 있습니다.
6. 키가 샌 것 같으면 AI Studio에서 그 키를 지우고 새로 만든 뒤, 이 앱 설정에 새 키를 넣습니다.
- 무료 사용량에는 1분당 한도와 하루 한도가 있습니다. 한도에 걸리면 설정의 다음 모델로 자동으로 넘어가고, 그래도 안 되면 쉬운 말로 알려 줍니다.

## 3. 작성 순서
1. **작성** 화면에서 반과 영역을 고릅니다.
2. 학생 행을 누르면 오른쪽 패널이 열립니다. 메모를 쓰고, 목표 분량(간결/표준/충실)과 드러낼 모습을 고릅니다.
3. **[초안 만들기]**를 누르면 초안이 최대 3개 나옵니다. 마음에 드는 것을 **[초안 칸에 저장]**하거나 **[최종본 끝에 붙이기]**로 옮긴 뒤 직접 다듬습니다. AI가 최종본을 덮어쓰는 일은 없습니다.
4. 여러 학생을 한꺼번에 하려면 **[일괄 초안]**을 누릅니다. 고른 학생이나 아직 안 쓴 학생만 차례로 만들고, 언제든 멈췄다가 이어서 할 수 있습니다. '완료'인 학생은 건너뜁니다.
5. 검사 단계에서 바이트, 기재 금지 표현, 나이스에서 깨지는 문자, 다른 학생과 거의 같은 글을 알려 줍니다. **[정리]**를 누르면 깨지는 문자와 겹친 띄어쓰기를 고칩니다. 경고가 있어도 저장은 됩니다.
6. 다 되면 **[완료로 표시]**를 누릅니다.
7. **현황** 화면에서 학생별·영역별 진행 상황을 한눈에 봅니다.

입력한 내용은 바로 이 브라우저에 저장되고, 구글 드라이브에 연결했다면 마지막 변경 3초 뒤 드라이브에도 올라갑니다. 머리 줄의 **[구글 드라이브에 저장]**을 누르면 기다리지 않고 바로 올립니다.

### 내 스타일
- **내 스타일** 화면에서 영역(공통, 자율·자치, 진로, 행동특성, 동아리, 교과세특 과목별)마다 예전에 쓴 글이나 마음에 드는 예시를 5개까지 넣습니다. 붙여넣기, `.txt` 파일, 엑셀·CSV 파일(열을 골라 칸마다 예시 하나)로 넣을 수 있습니다.
- 넣기 전에 명단에 있는 이름, 5자리 학번, 'n학년 n반 n번'을 'OO'으로 바꾼 결과와 바꾼 곳을 보여 줍니다. 확인한 뒤 **[이대로 저장]**을 누르세요. 그 밖에 다른 학생을 알아볼 수 있는 내용은 직접 지우고 넣어 주세요.
- '스타일 규칙'에 직접 규칙을 적거나(예: 한 문장은 짧게), **[AI로 스타일 정리]**로 예시의 문체 특징을 규칙으로 받아 고친 뒤 **[이 규칙 쓰기]**를 누릅니다.
- 초안을 만들 때 규칙과 짧은 예시 1~2개를 문체 참고로만 보냅니다. 예시의 활동이나 사실은 쓰지 않게 하고, '메모에 있는 사실만 쓴다'는 원칙이 언제나 먼저입니다. 작성 패널과 일괄 초안의 '내 스타일 적용'으로 끌 수 있습니다. 최종본에 예시와 같은 문장이 있으면 검사에서 알려 줍니다.
- 초안 후보는 그 자리에서 고칠 수 있고(고친 후보에 '고침' 표시), **[처음 상태로]**로 AI 원문에, **[이전 판]**으로 바로 전 글에 돌아갑니다. **[AI에게 다듬기 요청]**에 '더 짧게'처럼 적거나 빠른 요청을 누르면 같은 후보의 새 판으로 다듬어 줍니다(판은 3개까지). 다듬기에도 이름과 학번은 보내지 않습니다.

### 작성 화면 (표)
- **작성**은 반 전체를 명렬순 표로 보여 줍니다. 메모와 최종본 칸에서 바로 쓰면 칸 높이가 글 길이에 맞게 늘고 줄바꿈됩니다. 오른쪽 점검 열에 연속 공백, 문장부호 앞 공백, 자주 틀리는 맞춤법, 금지 표현, 한도 초과, 다른 학생과 비슷한 글이 표시되고, 고칠 수 있는 것은 [정리]로 한 번에 고칩니다 (맞춤법은 자주 틀리는 말만 찾으며 모든 오류를 찾지는 못합니다).
- 교과세특은 같은 과목 반이 여러 개일 때 반별 제목 줄로 나뉘어 한 표에 나옵니다. 제목 줄의 체크로 반 전체를, 줄마다 체크로 학생을 고릅니다.
- 학생을 고르면 [특징 쓰고 초안 만들기]가 나옵니다. 오른쪽 패널에서 1 대상 -> 2 공통 특징 -> 3 초안 만들기 -> 4 초안 수정 -> 5 [표에 순서대로 붙여넣기]를 합니다. 최종본 칸에 이미 글이 있을 때(건너뜀, 이어씀, 덮어씀)를 고르고, 붙인 뒤 [되돌리기]가 가능합니다. 완료한 학생은 건드리지 않습니다.
- 교과세특은 처음에 아무 반도 열리지 않고, 위의 "명단을 불러올 반"을 체크하면 그 반 명단이 표에 나옵니다. 여기서 체크한 학생들에게 쓸 때는 패널에서 **"후보를 만들어 학생에게 나눠 붙이기"**(교과세특 기본)를 씁니다: 공통 특징으로 후보 3개(최대 6개)를 만들고, 후보마다 이름 칩을 눌러 붙일 학생을 고르면(비슷한 학생끼리 한 후보) [표에 순서대로 붙여넣기]로 배정된 학생의 최종본 칸에 들어갑니다. 붙인 학생은 선택에서 빠지니 다음 무리를 이어서 고르면 됩니다. 학생마다 따로 만들려면 "학생마다 따로 만들기"를 고릅니다.
- 맨 위 [메모로 초안 만들기]는 메모를 적어 둔(최종본이 빈) 학생의 초안을 한꺼번에 최종본 칸에 만듭니다. 학생을 골라 두었으면 고른 학생만 합니다.
- **시작 준비 팝업**: 작성 도우미를 열 때 구글 드라이브가 연결되지 않았거나 API 키가 없으면, 한 팝업에서 [구글 드라이브에 연결]과 API 키 저장을 할 수 있습니다. [나중에]를 누르면 이번 창에서는 다시 묻지 않습니다.
- **AI 점검**: 작성 표 위의 'AI 점검'을 켜면 [AI로 점검 (N명)]이 나옵니다. 고른 학생(없으면 표의 학생) 중 최종본이 있는 학생의 맞춤법·띄어쓰기, 영역에 맞지 않는 내용, 나열식 문장을 AI로 보고 점검 칸에 'AI'로 붙입니다. 맞춤법과 고친 문장 제안은 [AI 고침 적용]으로 넣을 수 있습니다. 글을 고치면 그 학생의 AI 결과는 사라지니 다시 점검하세요. 이름과 학번은 가리고 보냅니다.
- **자율·진로 행사**: 일괄 작성 패널의 '행사' 칸에서 반의 행사(이름, 날짜 또는 기간)를 더하고 이번 글에 넣을 것을 체크합니다. 날짜는 `2026-5-14`, `5/14`처럼 적어도 기재요령 꼴(`2026.05.14.`, 기간 `2026.05.14.-2026.05.15.`)로 맞춥니다. 초안은 행사마다 `행사명(날짜)`로 시작하고, 초안에서 이 표기가 빠지면 '행사 표기 빠짐'이 뜹니다. 행사를 체크하면 붙여넣기가 '뒤에 이어씀'으로 바뀌어, 행사마다 만들어 최종본에 차례로 쌓을 수 있습니다. **추가 요청** 칸(예: 리더십 강조)은 강조점과 문장 모양에만 반영합니다.
- **교과세특 모둠**: 학생을 골라 패널의 [고른 N명으로 새 모둠 만들기]로 모둠을 만들고 모둠 공통 메모를 적으면, 초안을 만들 때 그 모둠 학생에게 모둠 메모가 들어갑니다. 표 위 모둠 버튼으로 모둠 학생을 한 번에 고릅니다. **체크한 성취기준은 도달한 것으로 보고 초안에 반드시 넣습니다** (아무것도 체크하지 않으면 반 전체 목록을 참고만).
- 담임 반은 자율·진로·행동특성만 쓰고, **동아리는 동아리 반에서** 씁니다. 동아리·교과 반의 표와 명단에는 학생의 학년-반이 함께 나옵니다 (예: 3-8 12).
- 교과세특·동아리 반에는 **칩 판**이 뜹니다. 반마다 번호·이름 칩을 눌러 고르고([반 전체], [반 해제]), 최종본이 있는 학생은 밑줄이 있습니다. 교과세특은 처음부터 "체크한 학생만"가 켜져 있어 고른 학생만 표에 나옵니다.
- 행의 [자세히]로 간 화면에서는 [표로 돌아가기]로 표에 돌아옵니다 (고른 학생과 패널 상태는 그대로).
- 교과세특의 **"체크한 학생만"**를 켜면 반을 가리지 않고 체크한 학생만 표에 남습니다 (명단이 길 때 확인용).
- **성취기준**: 명단 화면에서 반에 올려 둔 성취기준을 학생별로 체크하거나(행의 [성취기준]), 패널에서 이번 글에 포함할 것을 체크하면 그 내용을 포함해 글을 만듭니다. 체크하지 않으면 반 전체 성취기준을 AI에 알려 줍니다.
- 후보 개수는 **고른 학생 수 + 5개**(최대 40)이고, [배정 안 된 학생에게 후보를 차례로 하나씩]으로 학생마다 다른 후보를 자동 배정할 수 있습니다.
- **점검기로 보내기**: 표의 [점검기로 보내기]가 고른 학생(없으면 표의 모든 학생)의 최종본을 점검기에 넘기고 점검기를 엽니다. 점검기에서 고친 글은 작성 도우미로 되돌려 보내지 않습니다 (점검 결과를 보고 작성 도우미에서 직접 고칩니다). 화면 위의 "작성 | 점검"으로 두 도구를 오갈 수 있습니다.
- **명단 등록**에서 선택한 반이 있으면 학년·반이 자동으로 채워져(반 이름 '3학년 8반'이나 이미 등록된 학번에서) 붙여넣기·엑셀에 번호와 이름만 써도(`1 김가온`) 등록됩니다.
- 파일 올리기 칸(명단, 백업 가져오기, 나이스 엑셀 채우기)에는 파일을 끌어다 놓아도 됩니다.
- 이전의 학생별 패널(후보 3개 비교, 검사, NEIS 단계)은 행의 [자세히]로 열립니다.

## 4. 나이스에 옮기기
- **NEIS 옮기기** 화면에서 반과 영역을 고르면 '완료' 학생이 차례로 나옵니다. **[복사]** 후 나이스에 붙여 넣고 **[옮김, 다음]**을 누릅니다.
- 구글 드라이브에 연결되어 있으면 학교 PC 확장프로그램이 드라이브에서 완료 기록을 바로 가져갑니다 (확장프로그램 생기부 기능은 따로 준비 중).
- 드라이브 없이 쓸 때는 '드라이브 없이 보내기'를 펼쳐 **[확장프로그램으로 보내기]**로 글을 넘기거나, 'NEIS 입력 파일'을 내려받을 수 있습니다.

- **백업 화면의 "나이스 엑셀 양식에 채우기"**: 나이스에서 내려받은 특기사항 엑셀(자율·진로·동아리·행동특성·교과세특)을 고르면 학년·반·번호와 이름이 맞는 학생의 최종본을 본문 칸에 넣어 새 파일(`..._작성기채움.xlsx`)로 받습니다. 원본은 그대로이고 이미 글이 있는 칸은 기본으로 건드리지 않습니다(이어쓰기·덮어쓰기 선택). 글꼴·색 같은 꾸밈은 남지 않을 수 있습니다.
- 명단 등록 엑셀도 나이스 파일의 `반/번호`(예 8/1) 열을 읽습니다.

## 5. 저장 위치와 백업
- **구글 드라이브에 연결하면 드라이브가 원본입니다.** 명단, 반, 기록, 설정, 내 스타일이 선생님 구글 드라이브의 앱 전용 폴더(`sgb-data.json`)에 저장됩니다. 이 폴더는 드라이브 목록에 보이지 않고 공유되지 않습니다. 이 브라우저에는 인터넷이 끊겼을 때를 위한 사본만 둡니다.
  - 사이트 데이터가 지워지거나 학교 PC가 초기화되어도, 다시 연결하면 드라이브에서 전부 돌아옵니다. 다른 PC에서 연결해도 이어서 씁니다.
  - 연결은 처음 실행할 때의 안내, 머리 줄의 **[구글 드라이브 연결]**, 또는 **설정 > 구글 드라이브**에서 합니다. 학교 계정은 외부 앱이 막혀 있을 수 있으니 **개인 구글 계정**을 쓰세요.
  - 인터넷이 끊겨도 이 브라우저에 저장해 두었다가 연결되면 올립니다 ('연결되면 올립니다').
  - 날마다 첫 저장 때 드라이브에 자동 백업을 만들고 최근 7개를 남깁니다. **백업** 화면에서 그 날의 상태로 되돌릴 수 있습니다.
  - 여러 사람이 쓰는 PC라면 **설정 > 구글 드라이브 > 공용 PC**를 켜고, 일이 끝나면 **[연결 끊기] > 이 브라우저 사본도 지우기**를 누르세요.
- **연결하지 않으면** 데이터는 지금 쓰는 PC의 이 브라우저에만 저장됩니다 (머리 줄에 '드라이브 연결 안 됨' 경고가 보입니다). 브라우저 기록을 지우거나 PC를 바꾸면 사라질 수 있으니 백업 파일을 자주 받아 두세요.
- **백업** 화면의 **[백업 파일 내보내기]**로 파일을 받아 따로 보관할 수 있습니다. 다른 PC에서는 **가져오기**로 불러옵니다.
- 가져오기 전에 무엇이 바뀌는지 미리 보여 주고, 가져오기 직전 상태를 하나 자동으로 남겨 두어 **[가져오기 전 상태로 되돌리기]**를 할 수 있습니다. '완료'인 기록은 가져오기로 덮어쓰지 않습니다.
- 영역별 엑셀 내보내기도 있습니다.

## 6. 개인정보 주의
- **학생 이름과 학번은 AI로 보내지 않습니다.** 메모에 명단의 이름이나 학번이 들어 있으면 보내기 전에 '학생'으로 바꿉니다. 그래도 메모에 다른 개인정보(주소, 전화번호, 가족 사항, 건강 정보 등)는 쓰지 마세요.
- 백업 파일과 엑셀 파일에는 학생 이름이 들어 있습니다. **메신저나 메일로 다른 사람에게 보내지 마세요.** 보관은 학교 지침에 따라 주세요.
- Gemini(외부 AI) 사용이 학교·교육청 개인정보 지침에 맞는지 먼저 확인해 주세요.
- PC를 다른 사람과 같이 쓴다면 일이 끝난 뒤 **설정 > 모든 데이터 지우기**를 고려하세요.

## 7. 확인이 필요한 것
- 영역별 바이트 한도는 올해 학교생활기록부 기재요령 원문과 학교 기준으로 다시 확인해 주세요.
- 기재 금지 표현 목록은 기재요령의 원칙을 바탕으로 새로 만든 초안입니다. 항목별 근거는 `docs/forbidden-basis.md`에 있고, 원문 쪽수는 아직 확인하지 않았습니다. 설정에서 고치고 더할 수 있습니다.
- AI 초안은 초안일 뿐입니다. 사실과 맞는지 반드시 직접 확인해 주세요.

## 개발자용
- 빌드 없이 정적 파일로 돌아갑니다. 시험: 저장소 루트에서 `python -m http.server` 후 `http://localhost:8000/textgenerator-v2/?dev=1` (설정에 개발용 칸: 가짜 AI, 가짜 드라이브(새로고침 필요, 구글로 아무것도 보내지 않음), [사본만 지우기], 가상 학생 30명 반).
- 외부에서 불러오는 코드는 구글 로그인 스크립트(`accounts.google.com/gsi/client`) 하나뿐이며, 드라이브에 연결할 때 `js/drive.js`가 넣습니다.
- 테스트: `node textgenerator-v2/tests/run.mjs`
- 구조와 함수 계약: `docs/contract.md`, 검수 결과: `docs/review.md`
