# textgenerator-v2/lib/

외부 주소 대신 저장소에 넣어 쓰는 파일입니다. 파일 맨 위의 저작권·라이선스 주석이나 함께 둔 라이선스 파일을 지우지 마세요.

| 파일 | 이름 | 버전 | 라이선스 | 받은 곳 |
|---|---|---|---|---|
| `fonts/IBMPlexSansKR-Regular.woff2` (400), `-Medium.woff2` (500), `-SemiBold.woff2` (600) | IBM Plex Sans KR | 1.1.0 | SIL Open Font License 1.1 (`fonts/OFL-LICENSE.txt`) | npm `@ibm/plex-sans-kr` 1.1.0, `fonts/complete/woff2/hinted/` (2026-11-07) |

엑셀 처리용 SheetJS(0.18.5)는 저장소 공용 폴더 `../lib/xlsx.full.min.js`를 그대로 씁니다 (선생님 결정, 2026-11-07). 버전과 출처는 저장소 루트의 `lib/README.md`에 있습니다.

남는 외부 주소는 구글 로그인 스크립트(`https://accounts.google.com/gsi/client`) 하나입니다. 구글이 정한 방식이라 내려받아 쓸 수 없습니다.
