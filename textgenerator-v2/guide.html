생기부 작성 도우미

스마트 도구함으로

사용 안내

작성 도우미에서 반 전체 생기부를 쓰고 점검한 뒤, 학교 PC의 크롬 확장프로그램 생기부 도우미로 나이스에 반자동으로 입력합니다. 나이스 저장은 선생님이 확인한 뒤에만 합니다.

작성 도우미 열기 학교 PC 확장프로그램 받기 점검기 열기
1. 작성 도우미로 글 쓰기 2. 확장프로그램 설치 3. 나이스에 입력하기 4. 처음 시험하기 업데이트

1. 작성 도우미로 글 쓰기

  1. 명단에서 반을 만들고 학생을 등록합니다. 나이스 출석부 엑셀을 올리거나, 반을 고른 뒤 1 김가온처럼 번호와 이름만 붙여넣어도 됩니다. 파일은 끌어다 놓아도 됩니다.
  2. 작성에서 반 전체가 명렬순 표로 나옵니다. 메모와 최종본 칸에 바로 쓰고, 오른쪽 점검 칸에서 띄어쓰기·맞춤법·금지 표현·글자 수를 확인합니다.
  3. AI 초안: 표에서 학생을 체크하면 오른쪽에 초안 만들기 패널이 열립니다. 특징·드러낼 모습·목표 바이트를 정하고 초안을 만든 뒤 고쳐서 [표에 순서대로 붙여넣기]를 누릅니다. 교과세특은 반을 체크하고 칩 판에서 학생을 고르며, 성취기준을 체크하면 그 내용을 넣어 씁니다. 자율·진로는 학교 행사를 골라 넣을 수 있습니다.
  4. 필요하면 [점검기로 보내기]로 기재요령 기준으로 더 자세히 점검하고, 결과를 보고 작성 도우미에서 고칩니다.
  5. 다 쓴 글은 완료로 체크합니다. 나이스에는 완료한 글만 넘어갑니다.

AI를 쓰려면 설정에서 Gemini API 키를 넣습니다. 구글 드라이브에 연결해 두면 학교 PC 확장프로그램이 완료한 글을 바로 가져갑니다.

2. 학교 PC에 확장프로그램 설치 (약 5분)

그림을 따라 하면 됩니다. 단계를 누르면 해당 설명으로 이동합니다. 출결관리 도우미 확장과는 따로 설치합니다.

  1. 1설치 파일 받기sgb-extension.zip 내려받기
  2. 2압축 풀기지우지 않을 폴더에 풀어 둡니다
  3. 3확장 프로그램 관리 화면 열기크롬 주소창에 chrome://extensions
  4. 4개발자 모드 켜고 폴더 불러오기[압축해제된 확장 프로그램을 로드합니다]
  5. 5아이콘 고정갈색 종이와 연필 아이콘을 핀으로 고정
  6. 6나이스에서 사이드 패널 열기입력할 화면을 띄우고 아이콘 클릭
  7. 7입력하고 확인한 뒤 저장[입력 시작] → [확인 완료 · 저장] → [이대로 저장]
1

설치 파일 받기

학교 PC의 크롬에서 작성 도우미의 NEIS 옮기기 화면을 열고 '학교 PC 확장프로그램 받기와 설치'를 펼쳐 [확장프로그램 내려받기]를 누릅니다. 아래 버튼으로 바로 받아도 됩니다. sgb-extension.zip 파일이 다운로드 폴더에 저장됩니다.

sgb-extension.zip 내려받기
내려받기가 안 되거나 파일이 열리지 않아요
학교 보안 설정으로 압축 파일 내려받기가 막혀 있을 수 있습니다. 정보 담당 선생님께 문의해 주세요.
2

압축 풀기

받은 압축 파일에서 마우스 오른쪽 → 모두 압축 풀기를 누릅니다. 문서 폴더처럼 지우지 않을 곳에 두세요. 폴더를 지우면 확장프로그램도 사라집니다.

폴더 안에 같은 이름의 폴더가 한 번 더 들어 있어요
manifest.json 파일이 바로 보이는 안쪽 폴더를 4단계에서 고르면 됩니다.
3

확장 프로그램 관리 화면 열기

크롬 주소창에 아래 주소를 넣고 Enter를 누릅니다. 이 주소는 링크로는 열리지 않으니 [주소 복사]를 누른 뒤 주소창에 붙여넣기(Ctrl+V) 하세요.

chrome://extensions
주소를 열 수 없어요
크롬 오른쪽 위 점 세 개 메뉴 → 확장 프로그램 → 확장 프로그램 관리로도 열 수 있습니다.
4

개발자 모드 켜고 폴더 불러오기

  1. 오른쪽 위 개발자 모드 스위치를 켭니다.
  2. 왼쪽 위에 나타난 [압축해제된 확장 프로그램을 로드합니다]를 누릅니다.
  3. 2단계에서 푼 sgb-extension 폴더(manifest.json이 바로 보이는 폴더)를 고르고 [폴더 선택]을 누릅니다.

목록에 생기부 도우미 - 나이스 연동이 보이고 스위치가 켜져 있으면 설치된 것입니다. '개발자 모드' 경고가 뜨면 닫으면 됩니다.

[로드] 버튼이 보이지 않아요
개발자 모드가 꺼져 있는 것입니다. 오른쪽 위 스위치를 켜 주세요. 스위치를 누를 수 없으면 학교에서 막아 둔 것이므로 정보 담당 선생님께 문의해 주세요.
5

아이콘 고정

크롬 오른쪽 위 퍼즐 모양 아이콘을 눌러 생기부 도우미 - 나이스 연동 옆의 핀을 누르면 주소창 옆에 아이콘이 항상 보입니다. 생기부는 갈색 종이와 연필, 출결은 남색 체크 아이콘입니다.

6

나이스에서 사이드 패널 열기

  1. 나이스에서 입력할 생기부 화면(예: 자율·자치활동 특기사항)을 열고 학년·반을 [조회]합니다.
  2. 주소창 옆 생기부 도우미 아이콘을 누르면 오른쪽에 패널이 열리고 '나이스 생기부 화면 감지됨'이 보입니다. 입력하려는 탭이 화면에 보여야 켜집니다.
  3. 글 가져오기: 구글 드라이브에 연결했다면 [구글 드라이브에서 받기], 아니면 작성 도우미에서 받은 파일이나 엑셀을 [파일 불러오기]로 엽니다(패널에 끌어다 놓아도 됩니다). 완료한 글만 들어옵니다.
'새로고침(F5)하세요'라고 나와요
확장을 새로 설치하거나 업데이트하면 이미 열려 있던 나이스 탭은 새로고침해야 합니다. 나이스 탭에서 F5를 누르세요.
화면이 보이는데 감지되지 않아요
입력하려는 탭이 화면 앞에 있는지 확인하고, 나이스에서 [조회]를 한 번 누릅니다. 그래도 안 되면 F5를 누릅니다.
7

입력하고 확인한 뒤 저장

  1. [입력 시작]을 누르면 이 화면의 학생들에게 글이 들어갑니다. 아직 저장된 것은 아닙니다.
  2. 나이스에 이미 글이 있는 학생은 바로 바꾸지 않고 '선택 필요'로 남깁니다. [뒤에 이어쓰기] 또는 [덮어쓰기]를 고르세요('두 글 비교'로 확인).
  3. 나이스 표에서 글을 확인하고 [확인 완료 · 저장] → 목록 확인 → [이대로 저장]을 누릅니다.
  4. 마지막으로 저장할 학생 목록이 팝업으로 뜹니다. [확인]을 누르면 저장되고 나이스에 '자료의 저장이 완료되었습니다.'가 뜹니다.

저장 전에는 언제든 [멈추기]를 누르고 나이스 [조회]를 누르면 원래대로 돌아갑니다. 마감·확정 버튼은 확장이 절대 누르지 않습니다.

4. 처음 시험하기

처음에는 아래 순서로 안전하게 시험해 보세요.

  1. 학생 1명만 [입력 시작] 해 보고, 저장하지 말고 [멈추기]를 누릅니다.
  2. 나이스 [조회]를 눌러 원래대로 돌아오는지 봅니다.
  3. 이상이 없으면 학생 1명을 저장까지 해 보고, 그다음 여러 명을 합니다.

업데이트하기

새 버전이 나오면 학교 PC 크롬에서 작성 도우미를 열 때 '생기부 확장프로그램 새 버전이 있습니다' 알림이 뜨고, 사이드 패널 위쪽에도 안내가 표시됩니다. 알림에서 [내려받기]를 누르고 아래 순서대로 하세요. [나중에]를 누르면 다음 날 다시 알려 줍니다.

  1. 새 sgb-extension.zip을 받습니다. 지금 받기
  2. 압축을 풀어 기존 sgb-extension 폴더에 덮어씁니다.
  3. chrome://extensions를 열어 생기부 도우미의 새로고침(둥근 화살표)을 누릅니다.
  4. 나이스 탭을 새로고침(F5)합니다.

확장프로그램 [제거]는 누르지 마세요. 제거하면 이 PC에 불러 둔 글과 입력 기록이 지워집니다 (작성 도우미의 글은 그대로입니다).
